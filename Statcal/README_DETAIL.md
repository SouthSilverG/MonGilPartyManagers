# 상세 스탯 에디터

기존 파티 에디터 아래에 상세 스탯 에디터 탭을 추가했습니다. 캐릭터, 장비, 아티팩트, 몬스터링 선택은 두 탭에서 공유합니다.

## 사용 방법

1. 상세 탭에서 캐릭터 세 명을 선택하고, 맨 위에서 메인 요리와 사이드 요리를 선택합니다. 요리는 파티 전체에 적용됩니다.
2. 상단 캐릭터 버튼으로 세 명을 전환합니다. 캐릭터 돌파 0~6, 아티팩트 결합 1~5, 성소만 설정합니다. 캐릭터·아티팩트는 60레벨 및 레벨 돌파 완료로 고정합니다.
3. 장비를 선택한 뒤 공격력은 상수, 치확·치피는 %로 입력합니다. 5등급 18강 주옵션을 자동 적용합니다. 장갑 기본 공격력은 846이며 입력 공격력은 여기에 추가됩니다. 선택되지 않은 장비의 입력은 합산하지 않습니다.
4. 일반·전설 몬스터링은 프라임 5등급, 60레벨, 기본 스탯 그룹 A로 고정합니다. 왼쪽 선택 카드의 옵션 네 칸을 눌러 선택하면 원본 프라임 옵션 수치가 자동으로 적용됩니다. 별도 수치 입력은 없습니다.
5. 지원하는 효과는 체크 없이 자동 적용됩니다. 조건부 효과가 발동하고 최대 중첩에 도달한 상태를 가정하며, 캐릭터 속성과 돌파 단계로 적용 대상을 판단합니다.

캐릭터별 결과에는 해당 캐릭터의 주속성 피해만 표시합니다. 입력 중에도 결과가 갱신됩니다. 적용 출처를 펼치면 항목별 합산 내역을 볼 수 있습니다.

## PNG 호환

기존 `mongil-stardive-party` PNG 메타데이터와 버전 1 선택 항목을 유지하고 `detailedStats`만 추가합니다. 상세 설정 버전 2부터 장비 공격력은 상수입니다. 이전 상세 PNG의 공격력 % 입력은 0으로 초기화하므로 상수로 다시 입력하세요. 기존 PNG를 상세 탭에서 업로드하면 캐릭터·아티팩트·장비·몬스터링·옵션·전설 몬스터링이 복원됩니다. 상세 설정이 없는 기존 PNG는 상세 수치를 기본값으로 시작합니다.

상세 PNG를 파티 탭에서 업로드해도 공유 선택 항목이 복원됩니다. 상세 설정도 유지되므로 상세 탭으로 이동해서 계속 수정할 수 있습니다. 상세 탭의 저장 이름은 `상세 스탯 에디터_날짜_시간.png`입니다. 파티 탭의 기존 저장 이름은 유지됩니다.

## 계산 범위

- 클라이언트 추출 테이블에서 캐릭터·몬스터링·아티팩트 기본 스탯, 음식, 장비 세트 효과와 지원하는 전투 효과를 계산합니다.
- 공격력은 고정 공격력 합계에 공격력 증가 합계를 곱합니다. 치명타와 피해 증가는 퍼센트 포인트로 합산합니다. 변환 효과는 변환 전 스탯과 원본 상한을 사용합니다.
- 이자벨라·프란시스 서머 다이브·나래의 주요 파티 버프는 적용 대상과 돌파 대체 효과를 연결했습니다. 나래의 얼음 버프는 얼음 캐릭터만 받습니다.
- 링크체인과 적에게 거는 효과는 제외합니다. 성소는 상시 스탯 가호를 합산하며 해금 스킬의 조건부 효과는 자동 계산하지 않습니다.
- 모든 캐릭터의 전투 로직을 재현한 시뮬레이터는 아닙니다. 적용 대상은 원본 설명과 연결된 속성 조건으로 판단합니다. 미지원 효과는 화면에 표시하고 합산하지 않습니다. 원본 프라임 그룹에 없는 옵션은 미지원 경고를 표시합니다.
- 장비는 5등급 18강으로 가정하고 공격력·치확·치피 추가값만 직접 입력합니다. 몬스터링 옵션은 선택만 하면 프라임 수치가 자동 적용됩니다. 클라이언트 설정에서 확인된 상한을 적용하고 초과분을 별도로 표시합니다. 주속성·공격력 증가·보스 피해에는 확인되지 않은 상한을 임의로 넣지 않습니다.

## 파일과 검증

추가 파일: `Statcal/stats-data.js`, `Statcal/stats-engine.js`, `Statcal/stats-editor.js`, `Statcal/stats-editor.css`, `Statcal/foods/`, `assets/extracted/`. GitHub에 반영할 때 수정한 `index.html`, `app.js`와 함께 포함하세요.

`node tests/stats.test.cjs`로 파티 버프, 속성 대상, 돌파 대체, 중첩 상한, 음식, 스탯 변환, 입력 검증, 기존/상세 PNG 메타데이터 왕복을 검증합니다. 브라우저에서도 PNG 저장·업로드 및 부옵션 즉시 갱신을 확인했습니다.

데이터 재생성 스크립트는 `F:/MongilData/STARDIVE_Extract/build_editor_data.py`에 있습니다. 추출 테이블과 기존 선택 ID 매핑을 사용하며 새 클라이언트 패치 후에는 매핑과 전투 효과를 재검증해야 합니다.

상세 PNG는 세 캐릭터를 가로로 나란히 배치합니다. 공통 요리는 상단에 표시하며, 자동 적용 효과 목록·계산 안내·긴 원문은 저장 이미지에서 제외합니다. 전체 상세 설정은 PNG 메타데이터에 보존됩니다. 초상화는 배경 이미지로 비율을 유지하여 표시합니다.

관통률을 출력하고 방어력·체력은 출력하지 않습니다. 내부 체력·방어력 계산은 변환 효과 등을 위해 유지합니다. 관통률의 클라이언트 스탯 코드는 8이며, 확인되지 않은 관통률 상한은 임의로 적용하지 않습니다. 요리 선택 목록과 현재 선택 카드에 추출 아이콘 54개를 연결했습니다.
## 페이지 분리

파티 에디터: `index.html`, 원본 파티 렌더러와 스타일을 사용하며 PNG 너비는 2880px로 고정합니다. 상세 에디터: `Statcal/index.html`. 상세 전용 앱 코드·계산 엔진·테이블·스타일·요리 이미지는 `Statcal/`에 보관합니다. 기존 선택 데이터·캐릭터 이미지와 html2canvas 라이브러리는 공통 자원입니다. 과금 효율 페이지에서도 `../Statcal/index.html`로 이동합니다. 두 에디터 사이의 메뉴 이동과 PNG 업로드에서 파티 선택 및 상세 설정을 보존합니다.



## 역할 특화와 결합 전환
신발의 5등급 18강 역할 특화 2,775를 캐릭터 역할(난투·암살·파괴·지원)에 합산합니다. 아티팩트 전체 42종의 FUSION_VALUE_3 / FUSION_VALUE_5를 결합 단계에 따라 적용하며 ABILITY_TYPE 1389의 역할 능력치 전환 비율과 개별 상한을 사용합니다. 궁극 스킬 충전율도 표시합니다. 기본 결합 전환과 전투 발동 효과는 적용 출처에서 구분됩니다.


## 공용 설정
전설 몬스터링 옵션은 종류별 legendOptions에 저장하며 같은 종류를 장착한 캐릭터들이 공유합니다. 서로 다른 종류는 별도로 유지합니다. 옵션은 중복 없이 네 칸을 차례로 선택하며 모두 채워지면 창이 닫힙니다. 성소 레벨은 sanctuaryLevels에 속성별로 저장합니다. 이전 PNG의 슬롯별 설정은 같은 전설의 첫 유효 옵션, 같은 속성의 가장 높은 성소 레벨로 통합합니다. 성소의 상시 속성 피해와 해금 스킬의 조건부 스탯 효과를 함께 계산합니다. 성소 레벨에 따른 해금 단계와 캐릭터 돌파 분기를 선택하며, 속성별 수신 대상과 편성 인원 조건을 확인합니다.


## 성소·패시브·교체 연결
CHARACTER_SKILL_LEVEL의 실제 ACTION_ABILITY_GROUP_ID에서 조건/적용 연결(501·503)을 따라가 패시브·교체·지원·전투 스킬의 지원되는 스탯 효과를 수집합니다. 돌파 매개변수와 선택 스킬 레벨을 적용하며, 단순 ID 접두어 검색으로 미사용 효과를 더하던 방식을 제거했습니다. 서머 프란시스의 땅 피해 → 공격력 전환처럼 설명 테이블에 없는 연결도 원본 전환 매개변수로 계산합니다.
아티팩트의 무력화 피해 → 기본 공격 피해 전환도 계산하며, 특정 스킬 한정 공격력 증가는 일반 공격력에 섞지 않고 별도 항목으로 표시합니다. 전환 결과를 참조하는 다음 전환은 의존 순서로 계산하고, 순환 연결은 계산에서 제외해 알립니다.
자동 전투 출력은 조건부 효과 발동 및 최대 중첩 가정입니다. 회복·스태미나·적에게 거는 상태 이상·링크체인은 캐릭터 스탯 증가로 합산하지 않습니다. 모든 전투 시간과 적용 코드를 시뮬레이션하는 엔진은 아닙니다. 역할 능력치 자체의 피해 환산 공식은 아직 검증되지 않았으므로 원본에 직접 명시된 아티팩트 역할 전환과 구분합니다.

## 2026-10-10 추가 업데이트: 역할 피해 환산 구현

위 본문에서 역할 피해 환산을 미검증/미구현으로 적은 내용은 이 업데이트로 대체한다. 사용자가 제공한 1~100레벨 가중치 표를 positionWeights에 저장하고 역할 피해 환산을 구현했다. 공식은 `역할 스탯 × 해당 레벨 가중치 / 10000` 퍼센트 포인트. 현재 UI는 60레벨 고정이므로 가중치113, 계수0.0113을 사용한다. 난투→난전, 암살→제압, 파괴→무력화, 지원→지원 피해이며 **장착 캐릭터와 동일한 역할 스탯만** 환산한다. 자기 역할 비율 보너스가 있으면 역할 원시 스탯에 먼저 적용한다.

역할 전환은 스탯 전환 의존 순서에 포함하므로 그 결과를 참조하는 패시브/아티팩트도 반영한다. 이자벨라 파괴3853은 무력화 피해43.5389%가 되고 초전도체의 기본 공격 피해 전환과 특수 스킬 한정 공격력 전환, 이자벨라의 무력화→공격력 패시브에 연결된다. 아티팩트 결합의 파괴→치확/공격력 전환은 별도 유지한다.

출처는 **사용자가 대화에서 제공한 표와 공식**이다. 클라이언트에서 동일 계수표를 독립적으로 찾아 대조했다는 뜻은 아니다. 실게임 표시 반올림 및 복합 상한 적용 순서는 추가 대조 가능하다. 60레벨 네 역할, 1/60/100레벨 가중치, 이자벨라 연쇄 전환 테스트를 추가했다. 문서의 미검증 언급만 보고 역할 환산을 다시 제거하지 않는다.
